# Community Science Museum

Community Science Museum is a website made with HTML and CSS.

The website is designed to give visitors information about the museum, its exhibition spaces, special events, visiting information, and ways to get involved.

## Purpose

The purpose of this project was to create an informative and user-friendly museum website.

## Technologies Used

- HTML
- CSS

## Pages

The project includes these pages:

- **Home** – main landing page with links to important sections
- **Explore** – information for kids, teachers, and researchers
- **Exhibition Spaces** – overview of the museum exhibitions
- **Special Events and Exhibitions** – current museum events
- **Visit** – opening hours, location, admission, and accessibility
- **Get Involved** – information about support, volunteering, and internships
